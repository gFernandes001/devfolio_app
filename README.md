# DevFolio App (`devfolio_app`) - Projeto Final PPDM

Aplicativo desenvolvido em **Flutter / Dart** como Projeto Final da disciplina de **Programação para Dispositivos Móveis (PPDM)**, reunindo o **Perfil/Crachá do Desenvolvedor** e um **Dashboard de Métricas** interativo.

## Integrantes da Dupla
- **Guilherme Fernandes** (`@gFernandes001`)
- **Integrante 2** (`@Skavolsqn`)

## Componentes Desenvolvidos
- `lib/main.dart`: Estrutura principal da aplicação (`DevFolioApp` e `DevFolioHomePage`), gerenciamento de estado com `setState`, alternância entre perfis da dupla e layout responsivo.
- `lib/widgets/cracha_perfil.dart`: Widget `CrachaPerfil` exibindo identificação visual, status ativo, link do GitHub, turma/curso e tags de tecnologias.
- `lib/widgets/bloco_estatistica.dart`: Widget reutilizável `BlocoEstatistica` para exibição dos cards numéricos do Dashboard de Métricas.
